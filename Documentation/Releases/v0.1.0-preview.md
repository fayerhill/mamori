# Mamori 0.1.0 — Development preview

## English

A compact native macOS menu-bar app with English, Simplified Chinese, and Japanese UI. This first development preview uses system typography, standard controls, and adaptive light/dark appearance.

**Download for Apple silicon, macOS 14+:**

- `Mamori-macOS-arm64.dmg`: drag either app into Applications.
- `Mamori-macOS-arm64.zip`: the normal app, with real keep-awake and read-only GlobalProtect observation.
- `Mamori-Preview-macOS-arm64.zip`: a safe interactive simulation of guarding, VPN loss, keep-awake, and automatic app quitting.
- `SHA256SUMS`: download checksums. Every app package includes a Quick Start guide.

No Xcode or Terminal setup is needed for app downloads. These are **ad-hoc signed, non-notarized development builds**; macOS may block first launch. Follow the [download guide](https://github.com/fayerhill/mamori/blob/main/Documentation/Download.md).

**Network protection is not available in the normal download.** It requires a Developer ID signed helper and separately authorized live validation. Automatic app quitting requires an armed guard, so this release demonstrates it only in the safe preview. Keep-awake works independently in the normal app. There is no automatic VPN reconnection or claim of universal VPN support.

Recorded verification: 34 pure core tests passed; the app and helper were built, the native preview was checked, and packaged signatures/checksums were verified. Development verification did not disconnect a VPN, load PF rules, register a helper, or terminate user work apps. See [project progress](https://github.com/fayerhill/mamori/blob/main/Documentation/Progress.md).

## 简体中文

首个开发预览版采用简洁的 macOS 原生界面、系统无衬线字体和自适应明暗外观，支持英语、简体中文和日语。

下载适用于 **Apple Silicon、macOS 14+**。推荐使用 DMG，将所需应用拖入 Applications；也可单独下载普通版或安全预览版 ZIP。安装无需 Xcode 或终端配置，各包均附快速入门说明和独立的校验文件。

这是 **ad-hoc 签名、未公证的开发构建**，首次打开可能被 macOS 阻止，请参阅[下载说明](https://github.com/fayerhill/mamori/blob/main/Documentation/Download.md)。普通版可实际保持唤醒并只读观察 GlobalProtect；**尚不能启用真实断网保护**。自动退出应用也依赖已启用的网络守护，因此目前只能在安全预览中演示。真实保护仍需 Developer ID 签名和单独受控实测。

已记录 34 项核心测试通过，并完成构建、界面检查及安装包签名和校验值验证。开发验证没有断开真实 VPN、加载防火墙规则、安装后台服务或退出用户工作应用。详见[中文说明](https://github.com/fayerhill/mamori/blob/main/README.zh-CN.md)。

## 日本語

最初の開発プレビューです。macOS 標準のシンプルな UI、システムのサンセリフ書体、ライト／ダークモードに対応し、英語・簡体字中国語・日本語を利用できます。

対象は **Apple Silicon、macOS 14 以降**です。DMG からアプリを Applications にドラッグするか、通常版／安全なプレビュー版の ZIP を個別にダウンロードできます。Xcode や端末の設定は不要です。クイックスタートとチェックサムも提供します。

配布物は **ad-hoc 署名のみで、公証されていない開発ビルド**です。macOS が初回起動を阻止する場合は[ダウンロード手順](https://github.com/fayerhill/mamori/blob/main/Documentation/Download.md)を確認してください。通常版では実際のスリープ抑止と読み取り専用の GlobalProtect 監視を利用できますが、**実際のネットワーク遮断は有効にできません**。アプリの自動終了も有効な保護セッションが必要なため、安全なプレビュー内でのみ確認できます。実際の保護には Developer ID 署名と、別途管理された環境での検証が必要です。

コアテスト 34 件の成功、ビルド、画面確認、配布物の署名・チェックサム確認を記録しています。開発時の検証では、実 VPN の切断、PF ルールの適用、サービス登録、作業中のアプリの終了は行っていません。[日本語の説明](https://github.com/fayerhill/mamori/blob/main/README.ja.md)も参照してください。
