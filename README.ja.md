# Mamori

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md)

**Mamori · 守 · お守り** は、集中して作業するための小さなネイティブ macOS メニューバーアプリです。Mac のスリープを抑止し、VPN の切断が確認された際に終了するアプリを選択できます。対応範囲を限定したネットワーク保護の試作実装も含みます。

280 × 290 pt のコンパクトな画面は、macOS 標準のシンプルなスタイルです。システムのサンセリフ書体と標準コントロールを使い、ライト／ダークモードに対応します。開始ボタンにはシステムのアクセントカラー（標準は青）、停止には赤を使い、アプリ選択は自動終了の見出しの下に左揃えで配置しています。

**現在の状態：ローカル向け MVP。macOS 14 以降が必要です。** 標準の ad-hoc 署名ビルドでは、スリープ抑止と独立した安全なプレビューを利用できます。ネットワーク保護は実際の接続で未検証の実験的機能です。Developer ID 署名済みアプリとバックグラウンドサービス、および別途管理された環境での検証が必要です。現在のプレビューに実際のファイアウォール保護はありません。

## 機能

- **スリープ抑止**：Mamori の実行中、または指定した 1〜10,080 分間、Mac を起動状態に保ちます。画面の消灯とロックは利用できます。
- **アプリの選択**：インストール済みアプリを検索し、未起動のアプリも選択できます。確認された切断時に、選択済みで実行中のアプリだけが対象になります。
- **任意の自動終了**：初期設定はオフです。5 秒待ってからの強制終了も別途有効にできます。実行前にプロセスの同一性を再確認します。
- **VPN の監視**：GlobalProtect を読み取り専用で慎重に確認します。任意の `utun` インターフェイスだけでは、VPN 接続の証拠としません。
- **復元して終了**：保留中のアプリ終了処理を取り消し、スリープ抑止を解除して、ネットワーク設定の復元確認を待ちます。失敗時は再試行できます。
- **3 言語の UI**：英語、簡体字中国語、日本語を設定画面で切り替えられます。

スリープ抑止はネットワーク保護と独立しています。保護を停止してもタイマーは継続し、Mamori を終了すると両方が停止します。パネルを閉じてもメニューバーアプリは終了しません。VPN への自動再接続や、終了したアプリの再起動は行いません。

## ダウンロード

開発プレビュー版は [v0.1.0-preview のリリースページ](https://github.com/fayerhill/mamori/releases/tag/v0.1.0-preview) から入手できます。初回リリースは **Apple Silicon（arm64）、macOS 14 以降**が対象で、2 つのアプリを別々の ZIP として配布します。

- **Mamori-macOS-arm64.zip**：通常版の `Mamori.app` を含みます。スリープ抑止と読み取り専用の VPN 監視を利用できます。スリープ抑止は初期状態ではオフです。
- **Mamori-Preview-macOS-arm64.zip**：常に安全なシミュレーションで動作する `Mamori Preview.app` を含みます。実際の VPN、ファイアウォール、電源アサーション、他のアプリを操作せずに、画面と切断時の流れを確認できます。

各 ZIP にクイックスタートを同梱し、リリースページにはダウンロードファイルの検証用に `SHA256SUMS` も用意しています。

配布物は **ad-hoc 署名のみで、公証されていない開発ビルド**です。そのまま信頼できるネットワーク保護製品ではありません。アプリの自動終了には有効な保護セッションが必要なため、今回のダウンロードでは安全なプレビュー内でのみ動作を確認できます。実際の保護には Developer ID 署名済みアプリと `SMAppService` バックグラウンドサービス、および別途管理された環境での検証が必要です。導入は[ダウンロード手順](Documentation/Download.md)、削除は[インストール手順](Documentation/Installation.md)を参照してください。

## ビルドとプレビュー

macOS 14 以降、Xcode、Swift 6 が必要です。Swift Package Manager を使用し、外部パッケージへの依存はありません。

```sh
git clone https://github.com/fayerhill/mamori.git
cd mamori
./Scripts/build.sh
./Scripts/preview.sh
```

生成されるアプリは `build/Mamori.app` と `build/Mamori Preview.app` です。ビルド済み ZIP は Releases で配布し、ソースコードのディレクトリには含めません。プレビュー版は Finder から直接開いても必ずシミュレーションになります。インストール済みアプリの一覧とアイコンは読み取りますが、VPN、電源、ファイアウォール、アプリ終了の処理は模擬動作で、実際の VPN や他のアプリには変更を加えません。

隔離されたテストとプレビュー画像の生成：

```sh
./Scripts/test.sh
./Scripts/preview.sh --capture /private/tmp/mamori-preview
```

画像の生成はデモモード専用です。通常版では `--demo` が必要ですが、プレビュー版では自動的に有効になります。`/private/tmp` を使うと、Documents フォルダのアクセス権による保存失敗を避けられます。

## 構成

| モジュール | 役割 |
| --- | --- |
| `Sources/Mamori` | SwiftUI/AppKit の UI、ローカライズ、操作の調整 |
| `Sources/MamoriCore` | 純粋な状態遷移、VPN の証拠分類、ネットワークポリシー |
| `Sources/MamoriSystem` | 電源、アプリ、VPN、XPC のシステム連携 |
| `Sources/MamoriGuard` | `SMAppService` で管理する特権サービス、PF の試作実装、復元用の記録 |

コードとコード内のコメントは英語です。サービスには限定された操作だけを公開し、復元時は Mamori 自身が所有するネットワーク資源だけを扱います。

## 制約と検証範囲

- 初版の対象は限定的な GlobalProtect 構成です。すべての VPN、プロキシ、スプリットトンネルへの対応は約束しません。確認済みの IPv4 ゲートウェイと、指定したフルトンネルのインターフェイスが必要です。
- 外部 IPv4 アドレス 2 件への経路確認だけでは、**フルトンネルであることを証明できません**。フルトンネルは導入時の前提であり、実環境での検証が必要です。
- PF の試作実装には標準のフィルター入口が必要で、競合するルールや既存の状態テーブルがある場合は開始を拒否します。他のソフトウェアの接続状態を消去しません。
- 指定ゲートウェイと最小限の DHCP 通信は例外です。同じ許可済み IP を使うアプリを完全には区別できません。IPv6 の VPN ゲートウェイ通信は未対応で、漏えいゼロを保証しません。PF は Apple が製品用にサポートする API ではありません。
- スリープ抑止は、蓋を閉じる操作、明示的なスリープ、終了、再起動、低バッテリー時のスリープを防ぐ保証ではありません。リモートの AI ジョブの継続も保証しません。
- 自動再接続、ログイン時の自動起動、テレメトリーはありません。Shell 設定、PATH、DNS、プロキシ、GlobalProtect 設定は変更しません。削除時に OS のログ、承認記録、無関係な端末履歴やバックアップを消去しません。

記録済みのコアテストは **34 件成功、失敗 0 件**です。最新の書体変更は再ビルドと画面確認を行いました。これらは実際のネットワーク保護の検証ではありません。開発時の検証では、実 VPN の切断、サービス登録、PF ルールの適用、電源アサーションの取得、作業中のアプリの終了を行っていません。

## 今後の予定と文書

Developer ID 署名と公証を整え、管理されたテスト用 Mac でサービスの承認、復元、削除を検証します。その後、別途許可された環境で実通信の遮断、GlobalProtect との互換性、障害時の動作を確認します。広く配布する前に、長期的なネットワーク制御方式も評価します。
