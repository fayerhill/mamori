## 時間のかかる作業に、少しのゆとりを

| 操作 | できること |
| --- | --- |
| **Mac のスリープ抑止** | Mamori の実行中、または指定した時間だけ有効にできます。画面の消灯とロックはそのまま使えます。 |
| **GlobalProtect の保護** | 保護中は、手動切断でも予期しない切断でも、既定の拒否ポリシーを維持する実装です。ヘルパーが適用状態を検証し、結果を表示します。 |
| **選んだアプリを終了** | VPN 切断が確認された場合に、選択済みで実行中のアプリを任意で終了します。初期状態はオフ。不明な接続情報では終了せず、遅延後の強制終了も別途選べます。 |
| **復元して終了** | 予約済みのアプリ操作を取り消し、スリープ抑止を解除。自分の通信設定の復元を待って終了し、設定は次回に残します。 |
| **完全アンインストール** | 確認後に通信設定を復元し、サービス登録を解除してから、実行中のアプリと現在のユーザーの専用データを完全削除します。失敗は未完了として表示します。 |

スリープ抑止とネットワーク保護は独立しています。VPN の自動再接続や終了したアプリの再起動は行いません。ブラウザやターミナルの選択は、すべてのウィンドウとセッションを含むアプリ全体が対象です。

## 現在のバージョンを使い始める

1. [署名ガイド](Documentation/Signing.md)に沿って **0.2.0 をビルド・署名**します。ローカルの Apple Development 署名で実ヘルパーを利用できます。ad-hoc ビルドでは有効にできません。
2. クリーンな `build/Mamori.zip` を **Applications** に展開し、Mamori を開きます。ビルドスクリプトはサービスをインストール・起動しません。
3. GlobalProtect を接続し、Mamori の**保護を設定**を選びます。要求された場合は macOS でバックグラウンドサービスを承認します。
4. **VPN 接続を検出**を選び、検出されたトンネルとゲートウェイを確認してから**保護を開始**します。開始時の検証は認証済みヘルパーが担当し、メニューバー側の観測だけで判断しません。
5. 必要に応じてスリープ抑止とアプリの自動終了を有効にします。終えるときは**復元して終了**、削除するときは**設定 → 完全アンインストール**を選びます。

管理されたローカル環境で評価するための手順です。有効な署名、トンネルの検出、テストの成功は、実際の通信制限を証明するものではありません。

## 小さく作る理由

**Mac に馴染む操作。** システムの書体、標準コントロール、ライト／ダーク表示、三つの言語。パネルを閉じても、セッションは続きます。

**決めるのは使う人。** スリープ抑止とアプリの自動終了は初期状態でオフ。ログイン時の自動起動、VPN 再接続、アプリ再起動はありません。Mamori、VPN の制御アプリ、重要なシステムコンポーネントは終了対象から除外します。

**自分のものだけを管理。** テレメトリーはありません。Shell、PATH、DNS、プロキシ、GlobalProtect、システム全体の電源設定は変更しません。完全アンインストールも別コピー、ソース、他のユーザーのデータ、macOS のログや承認記録は削除対象外です。アプリはゴミ箱を経由せず削除します。

## 確認できていること

**Swift テスト 89 件が成功しました。** 以前の合成バンドル検査 6 件も成功していますが、今回は再実行していません。build 4 は Applications にインストール済みで、厳密な署名検証と起動を確認しました。実アプリのホームと設定を保護が無効な状態で確認し、保護セッションは開始していません。安全なプレビューも三言語で確認しました。修正した PF 読み取り処理は実機上のルールと一致し、別途行った非有効化の構文検査も通過しました。詳しい範囲は[検証記録](Documentation/Progress.md)にまとめています。

実際の VPN 切断、PF による通信制限、完全アンインストールの統合動作は**未検証**です。更新前にユーザーが「復元して終了」を実行し、PF 有効化前に失敗したセッションを整理できました。稼働中の PF からの復元を検証したわけではありません。現在の対象は限定された GlobalProtect 構成で、スプリットトンネル、プロキシ、すべての VPN への対応は含みません。二つの経路の抽出確認だけではフルトンネルを証明できません。スリープ抑止も蓋を閉じる操作や明示的なスリープを防がず、遠隔 AI の稼働継続を保証しません。評価前に[ネットワークの制約](Documentation/NetworkGuard.md)をご確認ください。

## 旧プレビューのダウンロード

公開中の **[v0.1.0-preview](https://github.com/fayerhill/mamori/releases/tag/v0.1.0-preview)** は Apple Silicon 向けの旧 ad-hoc 署名版で、公証されていません。通常版はスリープ抑止と読み取り専用の観測に対応しますが、実際の保護とアプリの自動終了は使えず、現在の 0.2.0 の機能は含みません。

旧版の導入は[ダウンロードガイド](Documentation/Download.md)をご覧ください。現在の UI を安全に試すには、別アプリの **Mamori Preview** をビルドできます。VPN、ファイアウォール、電源、アプリ終了、アンインストールを模擬し、実際に読み取るのはアプリ一覧だけです。実際の保護の評価には、上記の署名済みローカルビルドを使います。

<details>
<summary><strong>ビルド・仕組み・開発への参加</strong></summary>

Swift 6 に対応した Xcode が必要です。SwiftUI、AppKit、Swift Package Manager を使用し、外部パッケージへの依存はありません。

```sh
git clone https://github.com/fayerhill/mamori.git
cd mamori
SIGNING_MODE=dev ./Scripts/build.sh
./Scripts/preview.sh
./Scripts/test.sh
```

署名用 ID がなければ `SIGNING_MODE=adhoc` で制限付きビルドを作れます。`auto` は Developer ID、Apple Development、ad-hoc の順で選びます。公開用パッケージ処理は Apple Development ビルドを拒否します。[署名の詳細](Documentation/Signing.md)。

`Mamori` は UI、`MamoriCore` はセッションとポリシー、`MamoriSystem` はシステム連携、`MamoriGuard` は特権サービスを担当します。次の段階は管理された環境での統合検証と、Developer ID 署名・公証です。[問題の報告](https://github.com/fayerhill/mamori/issues)では、非公開の VPN アドレスや認証情報を含めないでください。

</details>
